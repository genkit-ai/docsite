[Genkit Dart](https://genkit.dev/docs/dart/overview/) 0.17 brings resumable generation and agent snapshots, background subagents, a pluggable telemetry architecture with the new `genkit_otel` package, and a curated OpenAI model catalog. Interrupted `generate` calls and agent turns now preserve completed tool rounds so you can inspect the failure and resume where execution stopped. Orchestrator agents can fan out subagents in the background, and you can export OpenTelemetry GenAI spans and metrics to any OTLP backend without pulling OpenTelemetry into core by default.

To start using this new version, run the following command in your terminal:

```shell
dart pub add genkit
```

## Keep progress across interrupted generate calls

When a multi-step tool loop fails on step four because of a rate limit or transient tool error, throwing an exception means losing all the work and tokens spent on the first three steps. In Genkit Dart 0.17, `ai.generate` preserves every completed tool round in `res.messages` whenever a run fails or is cancelled, so you can inspect `res.finishReason` and retry right where execution left off without re-running finished tools:

```dart
final controller = CancellationController();

final res = await ai.generate(
  model: googleAI.gemini('gemini-flash-latest'),
  prompt: 'Plan the itinerary and book the flights.',
  tools: [searchFlights, bookHotel],
  cancel: controller.token,
);

if (res.finishReason == FinishReason.failed) {
  print('Failed with status: ${res.error?.status}');
  // Pass res.messages back to retry from the last completed tool round:
  final retry = await ai.generate(
    model: googleAI.gemini('gemini-flash-latest'),
    messages: res.messages,
    tools: [searchFlights, bookHotel],
  );
  print(retry.text);
} else if (res.finishReason == FinishReason.aborted) {
  // Cancelled via controller.cancel() or reached maxTurns.
  // res.messages holds the clean turn boundary ready to resume.
} else {
  print(res.text);
}
```

## Resume failed or aborted agent snapshots

Stateful agents bring this same crash recovery to persistent chat sessions. When an agent turn fails or is cancelled mid-flight, Genkit automatically checkpoints the user prompt and any completed tool calls into a session snapshot before throwing `AgentError`. Pass `e.snapshotId` back to `agent.chat` to resume the turn from that checkpoint instead of asking the user to start over:

```dart
import 'package:genkit/experimental.dart';
import 'package:genkit/genkit.dart';

final chat = travelAgent.chat(sessionId: sessionId);

try {
  final res = await chat.send(text: 'Book the full itinerary.');
  print(res.text);
} on AgentError catch (e) {
  // Resume from the saved checkpoint containing completed tool calls:
  if (e.status == 'UNAVAILABLE' && e.snapshotId != null) {
    final rerun = travelAgent.chat(snapshotId: e.snapshotId);
    final recovered = await rerun.send();
    print(recovered.text);
  }
}
```

## Delegate work to background subagents

Regular subagents run inside a single tool call and block the main agent until every delegated task finishes, freezing the conversation during slow jobs like deep research reports or codebase audits. Setting `async: true` on the `agents` middleware lets your orchestrator launch subagents in the background and return a `taskId` immediately, so the main agent can reply to the user right away and keep the conversation moving while heavy work runs across turns.

Because background subagents run in their own tracked sessions outside the turn loop, the orchestrator can check in on progress, wait with a timeout to share partial results as faster tasks finish, cancel in-flight work the user no longer needs, or send follow-up instructions into a subagent's existing session without starting over:

```dart
import 'package:genkit/experimental.dart';
import 'package:genkit/genkit.dart';
import 'package:genkit_middleware/agents.dart';

final researcher = ai.defineAgent(
  name: 'researcher',
  description: 'Researches a single topic and returns a concise summary.',
  system: 'Return a tight 3-4 sentence summary of the topic.',
  store: InMemorySessionStore(),
);

final orchestrator = ai.defineAgent(
  name: 'asyncOrchestrator',
  system: 'Delegate each research topic in the background (background: true), '
      'then call wait_for_background_tasks with the returned taskIds.',
  use: [
    agents(agents: ['researcher'], async: true, maxDelegations: 8),
  ],
  store: InMemorySessionStore(),
);
```

## Pluggable telemetry and OpenTelemetry GenAI support

Core Genkit no longer pulls in OpenTelemetry dependencies by default, keeping your app's footprint small while local tracing still works automatically with the Genkit Developer UI. When you deploy to production, install the new [`genkit_otel`](https://pub.dev/packages/genkit_otel) package and register `GenAiInstrumentation` with `configureInstrumentation` to export traces, token usage, and operation latency following the OpenTelemetry GenAI semantic conventions:

```dart
import 'package:dartastic_opentelemetry/dartastic_opentelemetry.dart';
import 'package:genkit/genkit.dart';
import 'package:genkit/telemetry.dart';
import 'package:genkit_google_genai/genkit_google_genai.dart';
import 'package:genkit_otel/genkit_otel.dart';

Future<void> main() async {
  await OTel.initialize();
  configureInstrumentation(
    GenAiInstrumentation(contentCapturingMode: ContentCapturingMode.spanOnly),
  );

  final ai = Genkit(plugins: [googleAI()]);

  final res = await ai.generate(
    model: googleAI.gemini('gemini-flash-latest'),
    prompt: 'Explain OpenTelemetry in one sentence.',
  );
  print(res.text);

  await ai.shutdown();
  await OTel.shutdown();
}
```

## Curated OpenAI model catalog

The `genkit_openai` plugin now ships with a curated catalog of chat and embedding models with preconfigured capability presets for vision, tool calling, and structured outputs. Capabilities resolve automatically when you pass a model ID to `openAI.model`, or you can use the typed shortcuts on `OpenAIModels` and `OpenAIEmbedders` for IDE autocomplete:

```dart
import 'package:genkit/genkit.dart';
import 'package:genkit_openai/genkit_openai.dart';

Future<void> main() async {
  final ai = Genkit(plugins: [openAI()]);

  final res = await ai.generate(
    model: openAI.model('gpt-5.4-mini'),
    prompt: 'Summarize the key findings in three bullet points.',
  );
  print(res.text);
}
```

## Also in this release

* **Streamable HTTP and latest MCP spec.** `genkit_mcp` is now powered by the official `mcp_dart` SDK, adding support for the latest Model Context Protocol specification and Streamable HTTP servers.
* **Multi-turn extended thinking for Anthropic.** `genkit_anthropic` now preserves Claude's reasoning blocks across multi-step tool loops so extended thinking stays intact throughout complex workflows.
* **Gemma discovery and deterministic seeds.** `genkit_google_genai` adds built-in model discovery for Gemma alongside `seed` support for reproducible outputs.
