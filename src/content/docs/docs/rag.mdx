Retrieval-augmented generation grounds a model's answers in your own data. With
Genkit you can build it from parts you already know: embedders, flows, and the
`docs` you pass to a generate call. Write a flow that queries your database and
returns documents, and call it wherever you need context.

## What is RAG?

Retrieval-augmented generation is a technique used to incorporate external
sources of information into an LLM's responses. It's important to be able to do
so because, while LLMs are typically trained on a broad body of material,
practical use of LLMs often requires specific domain knowledge (for example, you
might want to use an LLM to answer customers' questions about your company's
products).

One solution is to fine-tune the model using more specific data. However, this
can be expensive both in terms of compute cost and in terms of the effort needed
to prepare adequate training data.

In contrast, RAG works by incorporating external data sources into a prompt at
the time it's passed to the model. For example, you could imagine the prompt,
"What is Bart's relationship to Lisa?" might be expanded ("augmented") by
prepending some relevant information, resulting in the prompt, "Homer and
Marge's children are named Bart, Lisa, and Maggie. What is Bart's relationship
to Lisa?"

This approach has several advantages:

- It can be more cost-effective because you don't have to retrain the model.
- You can continuously update your data source and the LLM can immediately
  make use of the updated information.
- You now have the potential to cite references in your LLM's responses.

On the other hand, using RAG naturally means longer prompts, and some LLM API
services charge for each input token you send. Ultimately, you must evaluate the
cost tradeoffs for your applications.

## How RAG fits together in Genkit

A typical RAG pipeline has three parts:

1. **Indexing.** Split source material into chunks, turn each chunk into an
   embedding with an [embedder](/docs/models), and write the chunk and its
   vector to a store. This usually runs as a batch job, or on a trigger when
   the source data changes.
2. **Retrieval.** Embed the user's query with the same embedder, ask the store
   for the nearest chunks, and return them as documents.
3. **Generation.** Pass the retrieved documents to the model along with the
   question.

In Genkit, indexing and retrieval can be ordinary [flows](/docs/flows). That
gets you typed inputs, tracing, a runner in the [Developer UI](/docs/devtools),
HTTP deployment, and the option to expose retrieval to the model as a
[tool](/docs/tool-calling). The store can be anything you can query from code:
PostgreSQL with pgvector, Firestore, a hosted vector database, a search engine,
or an in-memory list while you prototype.

## Example: menu Q&A

The following program indexes a restaurant menu and answers questions about it.
It keeps embeddings in memory so it runs with no database. The flows only touch
the store in two places, so moving to a real database later means replacing
those two spots.

<Lang lang="js">

```ts
import { googleAI } from '@genkit-ai/google-genai';
import { Document, DocumentDataSchema, genkit, z } from 'genkit';

const ai = genkit({
  plugins: [googleAI()],
  model: googleAI.model('gemini-flash-latest'),
});

const embedder = googleAI.embedder('gemini-embedding-001');

// A minimal in-memory vector store, good enough for prototyping. Data is lost
// when the process exits.
interface StoredChunk {
  text: string;
  metadata: Record<string, unknown>;
  embedding: number[];
}

const store: StoredChunk[] = [];

function cosineSimilarity(a: number[], b: number[]): number {
  let dot = 0;
  let normA = 0;
  let normB = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    normA += a[i] * a[i];
    normB += b[i] * b[i];
  }
  return dot / (Math.sqrt(normA) * Math.sqrt(normB));
}

// Indexing: chunk, embed, store.
export const indexMenu = ai.defineFlow(
  {
    name: 'indexMenu',
    inputSchema: z.object({
      source: z.string().describe('Where the text came from, such as a file name'),
      text: z.string(),
    }),
    outputSchema: z.object({ chunksIndexed: z.number() }),
  },
  async ({ source, text }) => {
    // One chunk per paragraph. See "Chunking" below for real splitters.
    const chunks = text
      .split(/\n\s*\n/)
      .map((c) => c.trim())
      .filter((c) => c.length > 0);
    if (chunks.length === 0) {
      return { chunksIndexed: 0 };
    }

    const embeddings = await ai.embedMany({
      embedder,
      content: chunks,
      options: { taskType: 'RETRIEVAL_DOCUMENT' },
    });
    chunks.forEach((chunk, i) => {
      store.push({
        text: chunk,
        metadata: { source, id: `${source}#${i}` },
        embedding: embeddings[i].embedding,
      });
    });
    return { chunksIndexed: chunks.length };
  }
);

export const RetrieveMenuInputSchema = z.object({
  query: z.string(),
  k: z.number().int().positive().optional().describe('Number of results, default 3'),
});

// Retrieval: a flow that returns documents.
export const retrieveMenu = ai.defineFlow(
  {
    name: 'retrieveMenu',
    inputSchema: RetrieveMenuInputSchema,
    outputSchema: z.array(DocumentDataSchema),
  },
  async ({ query, k = 3 }) => {
    const [{ embedding }] = await ai.embed({
      embedder,
      content: query,
      options: { taskType: 'RETRIEVAL_QUERY' },
    });
    return store
      .map((chunk) => ({ chunk, score: cosineSimilarity(embedding, chunk.embedding) }))
      .sort((a, b) => b.score - a.score)
      .slice(0, k)
      .map(({ chunk, score }) => Document.fromText(chunk.text, { ...chunk.metadata, score }));
  }
);

// Generation: call the retrieval flow like a function and pass its output as docs.
export const menuQA = ai.defineFlow(
  {
    name: 'menuQA',
    inputSchema: z.object({ question: z.string() }),
    outputSchema: z.string(),
  },
  async ({ question }) => {
    const docs = await retrieveMenu({ query: question });
    if (docs.length === 0) {
      return "I don't have the menu yet. Run indexMenu first.";
    }

    const { text } = await ai.generate({
      system: `You are acting as a helpful AI assistant that can answer
questions about the food available on the menu at Genkit Grub Pub.
Use only the context provided to answer the question. If you don't know, do not
make up an answer. Do not add or change items on the menu.`,
      prompt: question,
      docs,
    });
    return text;
  }
);
```

Calling a flow from inside another flow records it as a nested step, so traces
show the retrieved documents separately from the model call.

```go
package main

import (
	"cmp"
	"context"
	"fmt"
	"log"
	"maps"
	"math"
	"slices"
	"strings"
	"sync"

	"github.com/firebase/genkit/go/ai"
	"github.com/firebase/genkit/go/genkit"
	"github.com/firebase/genkit/go/plugins/googlegenai"
	"github.com/firebase/genkit/go/plugins/server"
	"google.golang.org/genai"
)

// storedChunk is one passage and its embedding.
type storedChunk struct {
	text      string
	metadata  map[string]any
	embedding []float32
}

// memStore is a minimal in-memory vector store, good enough for prototyping.
// Flows can run concurrently, so access goes through a mutex. Data is lost when
// the process exits.
type memStore struct {
	mu     sync.RWMutex
	chunks []storedChunk
}

func (s *memStore) add(chunks ...storedChunk) {
	s.mu.Lock()
	defer s.mu.Unlock()
	s.chunks = append(s.chunks, chunks...)
}

func (s *memStore) search(query []float32, k int) []*ai.Document {
	s.mu.RLock()
	defer s.mu.RUnlock()

	type hit struct {
		chunk storedChunk
		score float64
	}
	hits := make([]hit, 0, len(s.chunks))
	for _, c := range s.chunks {
		hits = append(hits, hit{c, cosineSimilarity(query, c.embedding)})
	}
	slices.SortFunc(hits, func(a, b hit) int { return cmp.Compare(b.score, a.score) })

	docs := make([]*ai.Document, 0, k)
	for _, h := range hits[:min(k, len(hits))] {
		md := maps.Clone(h.chunk.metadata)
		md["score"] = h.score
		docs = append(docs, ai.DocumentFromText(h.chunk.text, md))
	}
	return docs
}

func cosineSimilarity(a, b []float32) float64 {
	var dot, normA, normB float64
	for i := range a {
		dot += float64(a[i]) * float64(b[i])
		normA += float64(a[i]) * float64(a[i])
		normB += float64(b[i]) * float64(b[i])
	}
	return dot / (math.Sqrt(normA) * math.Sqrt(normB))
}

type IndexInput struct {
	Source string `json:"source"` // where the text came from, such as a file name
	Text   string `json:"text"`
}

type RetrieveInput struct {
	Query string `json:"query"`
	K     int    `json:"k,omitempty"` // number of results; 0 means 3
}

func main() {
	ctx := context.Background()
	g := genkit.Init(ctx,
		genkit.WithPlugins(&googlegenai.GoogleAI{}),
		genkit.WithDefaultModel("googleai/gemini-flash-latest"))

	// Gemini embedders take a different task type for each side.
	docEmbedder := googlegenai.EmbedderRef("googleai/gemini-embedding-001",
		&genai.EmbedContentConfig{TaskType: "RETRIEVAL_DOCUMENT"})
	queryEmbedder := googlegenai.EmbedderRef("googleai/gemini-embedding-001",
		&genai.EmbedContentConfig{TaskType: "RETRIEVAL_QUERY"})

	store := &memStore{}

	// Indexing: chunk, embed, store.
	genkit.DefineFlow(g, "indexMenu", func(ctx context.Context, in IndexInput) (int, error) {
		// One chunk per paragraph. See "Chunking" below for real splitters.
		var texts []string
		var docs []*ai.Document
		for _, p := range strings.Split(in.Text, "\n\n") {
			if p = strings.TrimSpace(p); p != "" {
				texts = append(texts, p)
				docs = append(docs, ai.DocumentFromText(p, nil))
			}
		}
		if len(docs) == 0 {
			return 0, nil
		}

		res, err := genkit.Embed(ctx, g, ai.WithEmbedder(docEmbedder), ai.WithDocs(docs...))
		if err != nil {
			return 0, err
		}
		chunks := make([]storedChunk, len(texts))
		for i, text := range texts {
			chunks[i] = storedChunk{
				text:      text,
				metadata:  map[string]any{"source": in.Source, "id": fmt.Sprintf("%s#%d", in.Source, i)},
				embedding: res.Embeddings[i].Embedding,
			}
		}
		store.add(chunks...)
		return len(chunks), nil
	})

	// Retrieval: a flow that returns documents.
	retrieveMenu := genkit.DefineFlow(g, "retrieveMenu",
		func(ctx context.Context, in RetrieveInput) ([]*ai.Document, error) {
			res, err := genkit.Embed(ctx, g, ai.WithEmbedder(queryEmbedder), ai.WithTextDocs(in.Query))
			if err != nil {
				return nil, err
			}
			return store.search(res.Embeddings[0].Embedding, cmp.Or(in.K, 3)), nil
		})

	// Generation: run the retrieval flow and pass its output as docs.
	genkit.DefineFlow(g, "menuQA", func(ctx context.Context, question string) (string, error) {
		docs, err := retrieveMenu.Run(ctx, RetrieveInput{Query: question})
		if err != nil {
			return "", err
		}
		if len(docs) == 0 {
			return "I don't have the menu yet. Run indexMenu first.", nil
		}

		return genkit.GenerateText(ctx, g,
			ai.WithDocs(docs...),
			ai.WithSystem(`
You are acting as a helpful AI assistant that can answer questions about the
food available on the menu at Genkit Grub Pub.
Use only the context provided to answer the question. If you don't know, do not
make up an answer. Do not add or change items on the menu.`),
			ai.WithPrompt(question))
	})

	// Keep the process alive so the CLI and the Developer UI can reach the
	// flows. Ctrl-C stops it.
	if err := server.Start(ctx, "127.0.0.1:3400", nil); err != nil {
		log.Fatal(err)
	}
}
```

```python
import math
from dataclasses import dataclass

from pydantic import BaseModel, Field

from genkit import Document, Genkit
from genkit_google_genai import GoogleAI

ai = Genkit(plugins=[GoogleAI()], model=GoogleAI.gemini('gemini-flash-latest'))

embedder = GoogleAI.embedder('gemini-embedding-001')


# A minimal in-memory vector store, good enough for prototyping. Data is lost
# when the process exits.
@dataclass
class StoredChunk:
    text: str
    metadata: dict[str, object]
    embedding: list[float]


store: list[StoredChunk] = []


def cosine_similarity(a: list[float], b: list[float]) -> float:
    dot = sum(x * y for x, y in zip(a, b, strict=True))
    norm_a = math.sqrt(sum(x * x for x in a))
    norm_b = math.sqrt(sum(y * y for y in b))
    return dot / (norm_a * norm_b)


class IndexInput(BaseModel):
    source: str = Field(description='Where the text came from, such as a file name')
    text: str


# Indexing: chunk, embed, store.
@ai.flow()
async def index_menu(input: IndexInput) -> int:
    # One chunk per paragraph. See "Chunking" below for real splitters.
    chunks = [p.strip() for p in input.text.split('\n\n') if p.strip()]
    if not chunks:
        return 0

    embeddings = await ai.embed_many(embedder=embedder, content=chunks)
    for i, (text, emb) in enumerate(zip(chunks, embeddings, strict=True)):
        store.append(
            StoredChunk(
                text=text,
                metadata={'source': input.source, 'id': f'{input.source}#{i}'},
                embedding=emb.embedding,
            )
        )
    return len(chunks)


class RetrieveInput(BaseModel):
    query: str
    k: int = Field(default=3, description='Number of results')


# Retrieval: a flow that returns documents.
@ai.flow()
async def retrieve_menu(input: RetrieveInput) -> list[Document]:
    [query] = await ai.embed(embedder=embedder, content=input.query)
    scored = sorted(
        ((cosine_similarity(query.embedding, c.embedding), c) for c in store),
        key=lambda hit: hit[0],
        reverse=True,
    )
    return [Document.from_text(c.text, {**c.metadata, 'score': score}) for score, c in scored[: input.k]]


# Generation: call the retrieval flow and pass its output as docs.
@ai.flow()
async def menu_qa(question: str) -> str:
    docs = await retrieve_menu(RetrieveInput(query=question))
    if not docs:
        return "I don't have the menu yet. Run index_menu first."

    response = await ai.generate(
        system=(
            'You are acting as a helpful AI assistant that can answer questions about the '
            'food available on the menu at Genkit Grub Pub. Use only the context provided '
            "to answer the question. If you don't know, do not make up an answer. Do not "
            'add or change items on the menu.'
        ),
        prompt=question,
        docs=docs,
    )
    return response.text
```

```dart
import 'dart:math' as math;

import 'package:genkit/genkit.dart';
import 'package:genkit_google_genai/genkit_google_genai.dart';
import 'package:schemantic/schemantic.dart';

part 'main.g.dart';

@Schema()
abstract class $IndexInput {
  /// Where the text came from, such as a file name.
  String get source;
  String get text;
}

@Schema()
abstract class $RetrieveInput {
  String get query;

  /// Number of results, default 3.
  int? get k;
}

/// One passage and its embedding.
typedef StoredChunk = ({
  String text,
  Map<String, dynamic> metadata,
  List<double> embedding,
});

/// A minimal in-memory vector store, good enough for prototyping. Data is lost
/// when the process exits.
final store = <StoredChunk>[];

double cosineSimilarity(List<double> a, List<double> b) {
  var dot = 0.0, normA = 0.0, normB = 0.0;
  for (var i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    normA += a[i] * a[i];
    normB += b[i] * b[i];
  }
  return dot / (math.sqrt(normA) * math.sqrt(normB));
}

void main() {
  final ai = Genkit(plugins: [googleAI()]);
  final embedder = googleAI.textEmbedding('gemini-embedding-001');

  // Indexing: chunk, embed, store.
  ai.defineFlow(
    name: 'indexMenu',
    inputSchema: IndexInput.$schema,
    outputSchema: SchemanticType.integer(),
    fn: (input, _) async {
      // One chunk per paragraph. See "Chunking" below for real splitters.
      final chunks = input.text
          .split(RegExp(r'\n\s*\n'))
          .map((c) => c.trim())
          .where((c) => c.isNotEmpty)
          .toList();
      if (chunks.isEmpty) return 0;

      final embeddings = await ai.embed(
        embedder: embedder,
        documents: [
          for (final c in chunks) DocumentData(content: [TextPart(text: c)]),
        ],
      );
      for (var i = 0; i < chunks.length; i++) {
        store.add((
          text: chunks[i],
          metadata: {'source': input.source, 'id': '${input.source}#$i'},
          embedding: embeddings[i].embedding,
        ));
      }
      return chunks.length;
    },
  );

  // Retrieval: a flow that returns documents.
  final retrieveMenu = ai.defineFlow(
    name: 'retrieveMenu',
    inputSchema: RetrieveInput.$schema,
    outputSchema: SchemanticType.list(DocumentData.$schema),
    fn: (input, _) async {
      final [query] = await ai.embed(
        embedder: embedder,
        document: DocumentData(content: [TextPart(text: input.query)]),
      );
      final hits = [
        for (final c in store)
          (chunk: c, score: cosineSimilarity(query.embedding, c.embedding)),
      ]..sort((a, b) => b.score.compareTo(a.score));
      return [
        for (final h in hits.take(input.k ?? 3))
          DocumentData(
            content: [TextPart(text: h.chunk.text)],
            metadata: {...h.chunk.metadata, 'score': h.score},
          ),
      ];
    },
  );

  // Generation: call the retrieval flow and add its output to the prompt.
  ai.defineFlow(
    name: 'menuQA',
    inputSchema: SchemanticType.string(),
    outputSchema: SchemanticType.string(),
    fn: (question, _) async {
      final docs = await retrieveMenu(RetrieveInput(query: question));
      if (docs.isEmpty) return "I don't have the menu yet. Run indexMenu first.";

      final context = docs
          .map((d) => '- ${d.content.map((p) => p.text ?? '').join()}')
          .join('\n');
      final response = await ai.generate(
        model: googleAI.gemini('gemini-flash-latest'),
        system: '''
You are acting as a helpful AI assistant that can answer questions about the
food available on the menu at Genkit Grub Pub.
Use only the context provided to answer the question. If you don't know, do not
make up an answer. Do not add or change items on the menu.''',
        prompt: 'Context:\n$context\n\nQuestion: $question',
      );
      return response.text;
    },
  );
}
```

### Chunking

The example splits on blank lines, which works for short, well-structured text.
For longer documents, use a splitter that targets a chunk size and keeps some
overlap between neighboring chunks, so that each chunk fits comfortably in the
prompt and a sentence cut at a boundary still appears whole in one of them.
Genkit does not ship a chunker.

<Lang lang="js">

[`llm-chunk`](https://www.npmjs.com/package/llm-chunk) is a small option:

```ts
import { chunk } from 'llm-chunk';

const chunks = chunk(text, {
  minLength: 1000,
  maxLength: 2000,
  splitter: 'sentence',
  overlap: 100,
});
```

</Lang>

<Lang lang="go">

The `textsplitter` package from `langchaingo` is one option:

```go
import "github.com/tmc/langchaingo/textsplitter"

splitter := textsplitter.NewRecursiveCharacter(
	textsplitter.WithChunkSize(1000),
	textsplitter.WithChunkOverlap(100),
)
texts, err := splitter.SplitText(text)
```

### Moving to a real database

The in-memory list is the only part of the example that you replace. Indexing
becomes an insert (or upsert) of text, metadata, and vector; retrieval becomes a
nearest-neighbor query. Keep the flow names and schemas the same, and the
`menuQA` flow doesn't change at all. The [vector store guides](#vector-store-guides)
show both halves for specific databases.

## Retrieval as a tool

Instead of always retrieving before generating, you can let the model decide
when to search, and with what query. Wrap the retrieval flow in a
[tool](/docs/tool-calling):

<Lang lang="js">

```ts
export const searchMenu = ai.defineTool(
  {
    name: 'searchMenu',
    description: 'Searches the Genkit Grub Pub menu. Returns menu items relevant to the query.',
    inputSchema: RetrieveMenuInputSchema,
    outputSchema: z.array(DocumentDataSchema),
  },
  (input) => retrieveMenu(input)
);

const { text } = await ai.generate({
  prompt: 'Is there anything vegan for dessert? And what about starters?',
  tools: [searchMenu],
});
```

</Lang>

```dart
      'Searches the Genkit Grub Pub menu. Returns menu items relevant to the query.',
  inputSchema: RetrieveInput.$schema,
  outputSchema: SchemanticType.list(DocumentData.$schema),
  fn: (input, _) async => ToolResult.response(await retrieveMenu(input)),
);

  model: googleAI.gemini('gemini-flash-latest'),
  prompt: 'Is there anything vegan for dessert? And what about starters?',
  tools: [searchMenu],
);
```

The model can now issue several searches for a multi-part question, or none at

## Reranking

Vector search is fast but approximate. A common improvement is two-stage
retrieval: over-fetch candidates with vector search, then rescore them with a
slower, more accurate method and keep the best few. Because retrieval is a flow,
reranking is just another step in it. The rescoring step can be a dedicated
ranking API, a cross-encoder model you host, or, as in this example, a Gemini
call with structured output:

<Lang lang="js">

```ts
const RelevanceSchema = z.object({
  scores: z.array(z.object({ index: z.number().int(), score: z.number().min(0).max(10) })),
});

export const retrieveMenuReranked = ai.defineFlow(
  {
    name: 'retrieveMenuReranked',
    inputSchema: RetrieveMenuInputSchema,
    outputSchema: z.array(DocumentDataSchema),
  },
  async ({ query, k = 3 }) => {
    const candidates = await retrieveMenu({ query, k: k * 5 });

    const { output } = await ai.generate({
      prompt: [
        'Rate how relevant each passage is to the query, from 0 (unrelated) to 10 (answers it).',
        `Query: ${query}`,
        ...candidates.map((doc, i) => `[${i}] ${new Document(doc).text}`),
      ].join('\n\n'),
      output: { schema: RelevanceSchema },
    });
    if (!output) {
      return candidates.slice(0, k);
    }

    return output.scores
      .filter(({ index }) => index >= 0 && index < candidates.length)
      .sort((a, b) => b.score - a.score)
      .slice(0, k)
      .map(({ index }) => candidates[index]);
  }
);
```

</Lang>

<Lang lang="go">

```go
type passageScore struct {
	Index int     `json:"index"`
	Score float64 `json:"score"`
}

type relevance struct {
	Scores []passageScore `json:"scores"`
}

retrieveMenuReranked := genkit.DefineFlow(g, "retrieveMenuReranked",
	func(ctx context.Context, in RetrieveInput) ([]*ai.Document, error) {
		k := cmp.Or(in.K, 3)
		candidates, err := retrieveMenu.Run(ctx, RetrieveInput{Query: in.Query, K: k * 5})
		if err != nil {
			return nil, err
		}

		var prompt strings.Builder
		fmt.Fprintf(&prompt, "Rate how relevant each passage is to the query, from 0 (unrelated) to 10 (answers it).\n\nQuery: %s\n", in.Query)
		for i, doc := range candidates {
			fmt.Fprintf(&prompt, "\n[%d] %s\n", i, doc.Content[0].Text)
		}
		rel, _, err := genkit.GenerateData[relevance](ctx, g, ai.WithPrompt(prompt.String()))
		if err != nil {
			return nil, err
		}

		slices.SortFunc(rel.Scores, func(a, b passageScore) int {
			return cmp.Compare(b.Score, a.Score)
		})
		var out []*ai.Document
		for _, s := range rel.Scores {
			if s.Index >= 0 && s.Index < len(candidates) && len(out) < k {
				out = append(out, candidates[s.Index])
			}
		}
		return out, nil
	})
```

</Lang>

```python
class PassageScore(BaseModel):
    index: int
    score: float = Field(ge=0, le=10)


class Relevance(BaseModel):
    scores: list[PassageScore]


@ai.flow()
async def retrieve_menu_reranked(input: RetrieveInput) -> list[Document]:
    candidates = await retrieve_menu(RetrieveInput(query=input.query, k=input.k * 5))

    passages = '\n\n'.join(f'[{i}] {doc.text}' for i, doc in enumerate(candidates))
    response = await ai.generate(
        prompt=(
            'Rate how relevant each passage is to the query, from 0 (unrelated) to 10 (answers it).\n\n'
            f'Query: {input.query}\n\n{passages}'
        ),
        output_schema=Relevance,
    )
    if response.output is None:
        return candidates[: input.k]

    ranked = sorted(response.output.scores, key=lambda s: s.score, reverse=True)
    return [candidates[s.index] for s in ranked if 0 <= s.index < len(candidates)][: input.k]
```

```dart
  int get index;
  double get score;

@Schema()
abstract class $Relevance {
  List<$PassageScore> get scores;
}

final retrieveMenuReranked = ai.defineFlow(
  name: 'retrieveMenuReranked',
  inputSchema: RetrieveInput.$schema,
  outputSchema: SchemanticType.list(DocumentData.$schema),
  fn: (input, _) async {
    final k = input.k ?? 3;
    final candidates =
        await retrieveMenu(RetrieveInput(query: input.query, k: k * 5));

    final passages = [
      for (var i = 0; i < candidates.length; i++)
        '[$i] ${candidates[i].content.map((p) => p.text ?? '').join()}',
    ].join('\n\n');
    final response = await ai.generate(
      model: googleAI.gemini('gemini-flash-latest'),
      prompt: 'Rate how relevant each passage is to the query, '
          'from 0 (unrelated) to 10 (answers it).\n\n'
          'Query: ${input.query}\n\n$passages',
      outputSchema: Relevance.$schema,
    );
    final output = response.output;
    if (output == null) return candidates.take(k).toList();

    final ranked = output.scores
        .where((s) => s.index >= 0 && s.index < candidates.length)
        .toList()
      ..sort((a, b) => b.score.compareTo(a.score));
    return [for (final s in ranked.take(k)) candidates[s.index]];
  },
```

## Filtering on relevance and access

Your retrieval flow owns the query, so the usual database features are
available to it directly:

- **Relevance floor.** The example copies the similarity score into each
  document's metadata. Drop results below a threshold, or return an empty list
  and let the calling flow answer "I don't know" without calling the model.
- **Metadata filters.** Add fields such as `category` or `locale` to the flow's
  input schema and pass them through to the query's `WHERE` clause or filter
  expression.
- **Authorization.** Filter by the caller's identity inside the flow, using the
  [auth context](/docs/deployment/authorization), never a value the model
  produced.

<Lang lang="go">

### Citations

Documents passed with `ai.WithDocs` land on the request's `Docs` field. What
happens next depends on the model:

- A model that declares `Supports.Context` receives the documents natively.
  Genkit inserts no markers, and rendering citations in your UI is up to you.
- Every other model goes through Genkit's augment-with-context middleware, which
  appends the documents to the last user message as lines of the form
  `- [<id>]: <text>`.

The bracketed key comes from `ai.AugmentWithContextOptions.CitationKey`. With
the default settings it is `Metadata["ref"]`, else `Metadata["id"]`, else the
zero-based index of the document. Set stable IDs at index time, as the
`indexMenu` flow above does, to make those citations addressable.

Only the document text and that one metadata value reach the model. The rest of
`Metadata` stays on your side, so you do not need to duplicate document text
into your prompt.

</Lang>

## Retriever and indexer actions

Genkit also has dedicated retriever and indexer action types, and some vector
store plugins provide ready-made ones. You can call them directly, or wrap one
in a retrieval flow so the rest of your code looks the same whichever store is
behind it.

</Lang>

<Lang lang="js">

```ts
import { devLocalRetrieverRef } from '@genkit-ai/dev-local-vectorstore';

const menuRetriever = devLocalRetrieverRef('menuQA');

// Call the retriever directly...
const docs = await ai.retrieve({
  retriever: menuRetriever,
  query: 'Recommend a dessert',
  options: { k: 3 },
});

// ...or wrap it in a flow with the same schema as the retrieveMenu flow above.
export const retrieveMenuFromPlugin = ai.defineFlow(
  {
    name: 'retrieveMenuFromPlugin',
    inputSchema: RetrieveMenuInputSchema,
    outputSchema: z.array(DocumentDataSchema),
  },
  ({ query, k = 3 }) => ai.retrieve({ retriever: menuRetriever, query, options: { k } })
);
```

`ai.index` is the indexing counterpart, and `ai.defineRetriever`,
`ai.defineSimpleRetriever`, and `ai.defineIndexer` let you define your own
actions of these types.

</Lang>
