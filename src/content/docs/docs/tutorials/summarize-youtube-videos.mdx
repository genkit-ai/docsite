## Implementation steps

After setting up your dependencies, you can build the project.

### 1. Set up your project

<Lang lang="js">

1. Create a directory structure and a file to hold
   your source code.

```bash
mkdir -p summarize-a-video/src && \
cd summarize-a-video && \
touch src/index.ts
```

2. Initialize a new TypeScript project.

```bash
npm init -y
```

3. Install the following Genkit dependencies to use Genkit in your project:

```bash
npm install genkit @genkit-ai/google-genai
```

- `genkit` provides Genkit core capabilities.
- `@genkit-ai/google-genai` provides access to the Google AI Gemini models.

4. Get and configure your model API key.

</Lang>

<Lang lang="go">

1. Create a directory for your project, initialize a Go module, and install the Genkit module:

```bash
mkdir summarize-a-video && \
cd summarize-a-video && \
go mod init example/summarize-a-video && \
go get github.com/firebase/genkit/go
```

2. Create a `main.go` file to hold your source code:

```bash
touch main.go
```

3. Get and configure your model API key.

</Lang>

<Lang lang="dart">

1. Create a new Dart console project and navigate into the directory:

```bash
dart create summarize_a_video && \
cd summarize_a_video
```

2. Add the `genkit` and `genkit_google_genai` packages:

```bash
dart pub add genkit genkit_google_genai
```

3. Get and configure your model API key.

</Lang>

<Lang lang="python">

1. Initialize a new Python project and install the Genkit and Google GenAI plugin packages:

```bash
uv init summarize-a-video && \
cd summarize-a-video && \
uv add genkit genkit-google-genai
```

2. Get and configure your model API key.

</Lang>

To use the Gemini API, which this tutorial uses, you must first
configure an API key. If you don't already have one,
[create a key](https://aistudio.google.com/apikey) in Google AI Studio.

The Gemini API provides a generous free-of-charge tier and does not require a
credit card to get started.

After creating your API key, set the `GEMINI_API_KEY` environment
variable to your key with the following command:

```bash
export GEMINI_API_KEY=<your API key>
```

:::note
Genkit also supports models via the Gemini Enterprise API, as well as from Anthropic, OpenAI, Cohere, Ollama, and more. See [Generating content](/docs/models/) for details.
:::

  Google's Gemini models.

### 6. Generate the response

Add the following code to pass a multimodal prompt containing both your text instruction and the YouTube video URL (`video/mp4`) to the model:

<Lang lang="js">

```typescript
// Step 3: process video
const { text } = await ai.generate({
  prompt: [
    { text: prompt },
    { media: { url: videoURL, contentType: 'video/mp4' } },
  ],
});
console.log(text);
```

This code snippet calls the `ai.generate` method to send a multimodal prompt to
the model. The prompt consists of two parts:

- `{ text: prompt }`: The text prompt that you defined earlier.
- `{ media: { url: videoURL, contentType: 'video/mp4' } }`: The URL of
  the video that you provided as a command-line argument, with `contentType`
  set to `video/mp4`.

</Lang>

<Lang lang="go">

```go
	// Step 3: process video
	resp, err := genkit.Generate(ctx, g,
		ai.WithMessages(
			ai.NewUserMessage(
				ai.NewTextPart(prompt),
				ai.NewMediaPart("video/mp4", videoURL),
			),
		),
	)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(resp.Text())
```

This code snippet calls `genkit.Generate` with a user message containing two parts:

- `ai.NewTextPart(prompt)`: The text prompt that you defined earlier.
- `ai.NewMediaPart("video/mp4", videoURL)`: The YouTube URL passed from the command line with the `video/mp4` MIME type.

</Lang>

<Lang lang="dart">

```dart
    // Step 3: process video
    final response = await ai.generate(
      model: googleAI.gemini('gemini-flash-latest'),
      messages: [
        Message(
          role: Role.user,
          content: [
            TextPart(text: prompt),
            MediaPart(
              media: Media(
                url: videoUrl,
                contentType: 'video/mp4',
              ),
            ),
          ],
        ),
      ],
    );
    print(response.text);
```

This code snippet calls `ai.generate` with a user `Message` containing a `TextPart` with your `prompt` and a `MediaPart` referencing the YouTube video URL with `contentType: 'video/mp4'`.

</Lang>

<Lang lang="python">

```python
    # Step 3: process video
    response = await ai.generate(
        prompt=[
            Part(root=TextPart(text=prompt)),
            Part(
                root=MediaPart(
                    media=Media(url=video_url, content_type='video/mp4')
                )
            ),
        ],
    )
    print(response.text)
```

This code snippet calls `ai.generate` with a multimodal prompt list containing a `TextPart` and a `MediaPart` referencing the YouTube video URL with `content_type='video/mp4'`.

</Lang>

### 7. Run the app

To run the app, open the terminal in the root
folder of your project, then run the following command:

<Lang lang="js">

```bash
npx tsx src/index.ts "https://www.youtube.com/watch?v=YUgXJkNqH9Q"
```

After a moment, a summary of the video you provided appears.

You can pass in other prompts as well. For example:

```bash
npx tsx src/index.ts "https://www.youtube.com/watch?v=YUgXJkNqH9Q" "Transcribe this video"
```
